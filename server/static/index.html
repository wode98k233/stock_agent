导入向导
拖入 skill zip 或选择目录
先预检，不会立即安装
1
识别导入类型：单 skill 或外部包。
2
检查路径安全、SKILL.md、工具列表和 build_tools。
3
展示变更预览：新增、覆盖、依赖、风险。
4
确认后复制到 user_skills 并重新扫描。
导入代码可能执行本地 Python。正式实现必须限制写入路径、限制包大小，并且不自动安装依赖。
推荐结构
最小可导入单 skill 包。
my_skill/
  SKILL.md
  main.py
  README.md          # optional
  requirements.txt   # optional
必须提供：`SKILL.md` 里的 YAML 头、目录层信息、工具列表；`main.py` 里的 `build_tools(logger, memory_mgr)`。
main.py 示例
推荐继承 SkillBuilder。
from tools.skill_builder import SkillBuilder, skill_tool

class MySkill(SkillBuilder):
    @skill_tool
    def get_demo_data(self, symbol: str) -> dict:
        """获取示例数据。"""
        return {"symbol": symbol}

def build_tools(logger, memory_mgr):
    return MySkill(logger, memory_mgr).build_langchain_tools()
