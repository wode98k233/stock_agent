# Skill名称：黄金阶段研判Skill
## 基础信息
- 版本：v1.0
- 描述：把「黄金现在处在什么阶段」拆成 6 个驱动力因子 + 1 个位置维度，输出读数 + 评分 + 九宫格阶段 + 信号命中 + 结论失效条件。**数据型技能**——只出判定，不产出报告。
- 所属分类：数据分析
- 适用场景：贵金属/资源板块择时、大类资产配置里的黄金权重判断、「黄金现在能不能买 / 什么位置 / 金价怎么看」这类问题

## 关联文件
- 工具注册入口：./main.py
- 计算引擎：`thesis/engine.py`（Web 台账页复用同一套，勿在技能层重复实现）
- 台账定义（阈值可手改）：`data/thesis/gold_regime.json`
- 定义加载与校验：`thesis/defs.py`
- 原始研究：用户资料库《黄金定价因子实证_跨资产相关性分析》（117 个月度观测）与《金价阶段研判》（六因子仪表盘）

## 目录层信息
- 关键参数：无（因子与阈值全部来自台账定义）
- 核心目标：按定义取数 → 区间打分 → 阶段判定；数据缺失标 `score=null`，不静默给 0 分
- 数据来源：`macro_indicator` 长表（合成美元指数 / 美债 2Y·10Y / 美国 CPI 同比 / 全球黄金 ETF 总库存 / 中国黄金储备 / 上海金 Au99.99 / 上海银基准价）；位置维度由上海金自算

## 工具列表
### 工具1：get_gold_env
- 功能：获取黄金阶段研判读数与综合判定
- 调用入口：main.py.build_tools 中的 get_gold_env
- 参数约束：无参数
- 返回结构：
  - `factors[]`：每项 `key/name/value/unit/score/status/detail/source/asof/stale/note/confidence`
    - `score` ∈ {-2,-1,0,1,2}，**null = 数据缺失，不等于中性**
    - `stale=true` → 引用时必须标注数据截止日（`asof`）
  - `total` 综合总分（仅统计有效因子，7 项满分标称 ±14、实际可达 ±13）、`valid_count` / `factor_count`
  - `verdict` / `action`：结论档位与对应动作
  - `stages`：**阶段矩阵（本台账的核心输出）**
    - `stage` 当前阶段名（9 个之一）/ `desc` 含义 / `tone` 方向（bull/warn/neutral/bear）
    - `drive_total` 驱动力（六因子之和，满分 ±11）/ `drive_band`（顺风 / 中性 / 逆风）
    - `pos_score` 位置得分 / `pos_band`（低位 / 中性位 / 高位）
    - `complete` 驱动力是否全部因子有效；`drive_missing` 缺失的因子 key
    - `cells[]` 九宫格全部格子（`current=true` 即当前格）
  - `signals.buy[]` / `signals.warn[]`：`label/current/hit`
  - `invalidation[]`：`text/current/hit` —— **结论失效条件，命中即说明多头结论不再成立**
  - `scenarios[]` / `transmission[]` / `phases[]`：情景推演 / 传导链路 / 历史阶段（均不参与打分）
  - `metric_values`：各指标原始读数（供交叉引用）
  - `warnings[]`：取数降级、数据陈旧等提示
- `factors` 的 key 固定为：`dxy`（美元指数）/ `us2_y`（美债 2Y）/ `real`（实际利率代理）/ `gold_etf`（黄金 ETF 库存）/ `agratio`（金银比）/ `cn_gold`（中国黄金储备）/ `position`（价格位置）

### 工具2：describe_gold_thesis
- 功能：返回台账元信息（名称、标的口径、因子清单、结论档位、定义校验问题）
- 参数约束：无参数
- 使用时机：用户问「这个台账怎么算的 / 有哪些因子」时用；**不要**用它取当前读数

## 使用指南

### 适用场景
- 用户问「黄金/金价现在什么位置、能不能买」→ 先取本因子包，再结合估值与持仓
- 板块择时：作为「贵金属环境是否顺风」的定量输入
- **结论失效条件必须一起呈现**：不能只报总分，命中失效条件时须显式说明

### 不适用场景
- 不选个股（金矿股、贵金属 ETF 的选股是选股流程的职责，本技能只给环境）
- 不做金价点位预测（本台账给阶段与档位，不给目标价）
- 不提供买卖指令

### 输出解读要点（**口径诚实性，务必遵守**）
- **两个维度不可混为一个总分看**：`stages.stage` 才是本台账的主结论。
  「驱动有利 + 位置已高」与「驱动有利 + 位置便宜」总分相近（都是顺风档），
  但前者是「持有可以、追高不宜」、后者是「历史上最优的组合」——必须按 `stage` 表述。
- `total` 满分标称 ±14（7 因子 × ±2），**实际可达 ±13**：⑥ 中国黄金储备刻意只给 ±1。
  驱动力满分同理是 ±11 而非 ±12（见 `stages.drive_full`）。不要按 12/14 归因「差几分」。
- **③ 实际利率（代理）是失效口径**：相关性 +0.153（正号，与理论相反），因为
  「10Y名义 − CPI同比」是事后实际利率，而市场用 TIPS（前瞻）定价。**不能据此否定
  「实际利率是黄金核心驱动」**，只能说本代理口径失真。该因子 `confidence=low`，
  引用时应明确说明；若它的分数主导了结论，须提示读者结论可靠性下降。
- **④ 黄金 ETF 库存是同步/滞后指标**（r=+0.468 但因果方向不可分离）：
  可用于「同步确认需求」，**不可作为领先指标或买入理由**（那是拿结果推原因）。
- **⑥ 中国黄金储备是慢变量**（月度相关性仅 +0.044）：只表达「长期底是否还在增厚」，
  不用于择时。它与金价的低相关是**时间尺度不匹配**，不是「央行购金不重要」。
- **⑦ 位置读数本身就是分位**（0~100%）：不要再对它算一次「历史分位」。
- 相关性与 `stages` 的阈值切点（驱动 ±4/−3、位置分位 10/30/70/90）是**主观设定**，
  引用时须说明这一点；三段历史阶段划分（低利率宽松 / 加息 525bp / 重启加息）出自原始研究。

### 失败 fallback
- 返回 `{"error": ...}` 时优先检查：① `data/thesis/gold_regime.json` 是否完整；
  ② `macro_indicator` 表里的 `dxy / us2_y / us10_y / us_cpi_yoy / gold_etf_holdings /
  cn_gold_reserve / au_sge / ag_sge` 是否已同步（新库首次运行需先拉一遍）
- 部分因子 `score=null` 不算整体失败：用 `valid_count` 说明有效因子数继续分析；
  若 `stages.complete=false`，须显式说明「驱动力只累加了 N/M 个因子，档位可能偏移」
- `gold_etf_holdings` 的源接口全量约 21s（已单独放宽调用预算），首次同步慢属正常

### 不要重试条件
- 同一轮对话内不要重复调用（单次调用已含全部 7 因子）
- 返回 `error` 时不要连读同参重试；接口不可达时重试无意义

### 阈值调整
- 改 `data/thesis/gold_regime.json` 的 `thresholds` / `params` / `stages`，**无需重启**（带 mtime 缓存）
- 阈值表格式：`[下限, 上限, 得分]`，下限含、上限不含；定义被改动后建议顺手跑一次
  `thesis.defs.validate_def()` 确认无「区间未覆盖」问题
- 若改动了 `stages.drive_keys` 或某个因子的得分幅度，务必同步复核 `stages.drive_full`
  与 `verdicts` 的 `min_total` 档位（量纲变了档位含义会整体漂移）
