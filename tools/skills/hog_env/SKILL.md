# Skill名称：猪周期研判Skill
## 基础信息
- 版本：v1.0
- 描述：把「生猪养殖行业现在处在什么周期阶段」拆成 3 个产能出清因子 + 3 个价格预期因子，输出读数 + 评分 + 九宫格阶段 + 信号命中 + 结论失效条件。**数据型技能**——只出判定，不产出报告。
- 所属分类：数据分析
- 适用场景：农业/养殖板块择时、猪周期位置判断、「猪价怎么看 / 现在是不是周期底部 / 养殖能不能布局」这类问题

## 关联文件
- 工具注册入口：./main.py
- 计算引擎：`thesis/engine.py`（Web 台账页复用同一套，勿在技能层重复实现）
- 台账定义（阈值可手改）：`data/thesis/hog_regime.json`
- 定义加载与校验：`thesis/defs.py`
- 原始研究：用户资料库《猪周期研判》仪表盘（web 节点 qF6A3GseNKYrpBqjvlVC8a / lff8J8DwmGQomCvdoXQlWO）与《猪周期深度研究_当前位置与反转路径_2026-09-28》（web 节点 u2kXpZSQ55OaWk6dFaQKg9），配套源码 hog_regime.py / hog_config.json
- ⚠️ **同目录兄弟技能**：`gold_env`（贵金属）、`cu_env`（工业金属）——三者共用 `ThesisSkill` 薄封装，**阈值符号绝不可互相照抄**（资产属性不同，方向可能相反）

## 目录层信息
- 关键参数：无（因子与阈值全部来自台账定义）；**能繁母猪为手工维护项**（`manual.sow`，官方月度数据，发布滞后约 1 个月，超期会显式告警）
- 核心目标：按定义取数 → 区间打分 → 阶段判定；数据缺失标 `score=null`，不静默给 0 分
- 数据来源：`macro_indicator` 长表（生猪现货指数 / 搜猪网生猪现货价 / 玉米现货价 / 生猪期货主连）+ 手工维护的能繁母猪存栏

## 工具列表
### 工具1：get_hog_env
- 功能：获取猪周期研判读数与综合判定
- 调用入口：main.py.build_tools 中的 get_hog_env
- 参数约束：无参数
- 返回结构：
  - `factors[]`：每项 `key/name/value/unit/score/status/detail/source/asof/stale/note/confidence`
    - `score` ∈ {-2,-1,0,1,2}，**null = 数据缺失，不等于中性**
    - `stale=true` → 引用时必须标注数据截止日（`asof`）；② 能繁母猪为手工项，过期会告警
  - `total` 综合总分（仅统计有效因子，6 项满分 ±10）、`valid_count` / `factor_count`
  - `verdict` / `action`：结论档位与对应动作
  - `stages`：**阶段矩阵（本台账的核心输出）**
    - `stage` 当前阶段名（9 个之一）/ `desc` 含义 / `tone` 方向（bull/warn/neutral/bear）
    - `drive_total` 驱动力（三出清因子之和，满分 ±5）/ `drive_band`（出清充分 / 出清中 / 出清不足）
    - `pos_total` 价格与预期（三因子之和，满分 ±5）/ `pos_band`（价格低位 / 价格中位 / 价格高位）
    - `pos_keys`（三因子 key 列表）/ `complete` 两轴是否全部因子有效 / `drive_missing` / `pos_missing`
    - `cells[]` 九宫格全部格子（`current=true` 即当前格）
  - `signals.buy[]` / `signals.warn[]`：`label/current/hit`
  - `invalidation[]`：`text/current/hit` —— **结论失效条件，命中即说明多头（左侧布局）结论不再成立**
  - `scenarios[]` / `transmission[]` / `phases[]`：情景推演 / 传导链路 / 历史阶段（均不参与打分）
  - `metric_values`：各指标原始读数（供交叉引用，含 `sow_dev_pct` 去化幅度）
  - `warnings[]`：取数降级、手工项过期等提示
- `factors` 的 key 固定为：`ratio`（猪粮比代理）/ `sow`（能繁母猪去化）/ `weight`（出栏均重）/ `rank`（猪价历史分位）/ `basis`（期现价差）/ `ma12`（现货 vs 12 月均线）

### 工具2：describe_hog_thesis
- 功能：返回台账元信息（名称、标的口径、因子清单、结论档位、定义校验问题）
- 参数约束：无参数
- 使用时机：用户问「这个台账怎么算的 / 有哪些因子」时用；**不要**用它取当前读数

## 使用指南

### 适用场景
- 用户问「猪价现在什么位置、养殖能不能布局」→ 先取本因子包，再结合个股（牧原/温氏/巨星）成本与杠杆
- 板块择时：作为「养殖板块周期位置」的定量输入
- **结论失效条件必须一起呈现**：不能只报总分，命中失效条件时须显式说明

### 不适用场景
- 不选个股（猪企的成本与杠杆分化是「谁能活到反转」的关键，但属个股维度，本技能只给行业周期）
- 不做猪价点位预测（本台账给阶段与档位，不给目标价）
- 不提供买卖指令

### 输出解读要点（**口径诚实性，务必遵守**）
- **两个维度不可混为一个总分看**：`stages.stage` 才是本台账的主结论。
- **⭐ B 轴（价格与预期）方向与 cu_regime 相反**：`pos_total` **正分 = 价格高位**、
  **负分 = 价格低位**。原始 hog_regime.py 即如此：`if B <= -2: 价格低位`。
  故 `pos_total = −3` **不是「不利」**，而是「价格处低位」。**不要把 cu_env 的 B 轴
  「正分 = 便宜」搬过来**。该轴由 3 个因子**求和**（`pos_keys`：rank+basis+ma12）。
- **周期根源是约 10 个月刚性生理时滞**：能繁配种 → 妊娠 114 天 → 育肥 6 个月。
  猪价高时所有人同时扩产，10 个月后供给集中释放；猪价低时同时去产能，10 个月后供给收缩。
  **反转的领先指标是能繁母猪存栏，不是猪价本身**（约 10 个月后传导至出栏）。
- **「母猪少了」不等于「猪少了」**（最大不确定性）：PSY（每头母猪年提供断奶仔猪数）
  从 19.9 提升到 23.4（头部超 28），3780 万头 × 23.4 的理论出栏能力并不低于过去
  4042 万头 × 19.9。PSY 无公开时序，**拿不到**，只能靠失效条件定性兜底。
- **政策是基准标尺的设定者，不是外生冲击**：2026-06《生猪产能综合调控实施方案（2026年修订）》
  把正常保有量目标从 3900 下调至 3750 万头（理由是 PSY 提升）。
  **用旧目标 3900 去算，去化幅度会看起来远不够。** 用旧标尺读本台账会系统性误判。
- **① 猪粮比代理口径**：搜猪网生猪现货 ÷ 搜猪网玉米现货（官方口径无稳定接口）。
  实测与官方高度接近（首跑 4.30 vs 官方 4.57）。**方向是「越低越有利」**（左侧逻辑：
  深度亏损 → 去化动力最强）。5:1 是官方一级预警线，也是收储触发线（政策底信号）。
- **③ 出栏均重是行为信号**：均重下降 = 主动去化/提前出栏（利多远期供给收缩，正分）；
  上升 = 压栏或二次育肥回升（透支远期供给，负分）。**注意它是周频序列**，
  「20 期」实为 20 周而非 20 个交易日，且未做季节性调整。
- **⑤ 期现价差方向是「升水为正」**（与 cu_env 的「贴水有利」相反）：升水 = 市场已确认反转。
- **⑥ 现货 vs 12 月均线**：高于均线 = 正分（价格已进入上行区间）。**必须用现货指数
  （index）而不是成交均价（price）**——源自带的 12 月均线是对指数算的，用均价去除会口径错配。
- **主标的取生猪现货指数而不是期货**：期货只反映预期，本台账要判「产业实际出清到哪一步」。
- **2027 年反转是预测不是事实**：本台账并列呈现基准（概率 50%）与审慎（反方，概率 30%）
  两种情景，两者都有数据支撑。引用时不得表述为确定性结论。
- **⚠️ 首跑读数**：出清进度 A=+3（出清充分）、价格预期 B=−3（价格低位）→ **左侧布局期**
  （2026-09-28）。

### 失败 fallback
- 返回 `{"error": ...}` 时优先检查：① `data/thesis/hog_regime.json` 是否完整；
  ② `macro_indicator` 表里的 `hog_spot_index / hog_spot_price / hog_spot_weight /
  hog_spot_ma12 / hog_lean_spot / corn_spot / hog_fut_main` 是否已同步
- **② 能繁母猪是全台账最核心的领先指标**：若 `sow` 因子 `stale=true`（超 120 天未更新），
  整个「出清进度」判定失去依据，**必须显式提示用户更新 `manual.sow` 后再引用结论**
- 部分因子 `score=null` 不算整体失败：用 `valid_count` 说明有效因子数继续分析；
  若 `stages.complete=false`，须显式说明「只累加了 N/M 个因子，档位可能偏移」
- 生猪期货 2025-09 才上市（仅约 367 个日频观测），⑤ 期现价差与现货共同日仅约 48 个，
  历史深度显著短于其它因子，稳健性弱——引用时须说明

### 不要重试条件
- 同一轮对话内不要重复调用（单次调用已含全部 6 因子）
- 返回 `error` 时不要连读同参重试；接口不可达时重试无意义

### 阈值调整
- 改 `data/thesis/hog_regime.json` 的 `thresholds` / `params` / `stages`，**无需重启**（带 mtime 缓存）
- **更新能繁母猪**：改 `manual.sow.value` / `updated_at`（同时可更新 `peak` / `target`），
  阈值作用在**去化幅度**（(1 − value/peak) × 100）上，由 `derive` 在引擎侧派生
- 阈值表格式：`[下限, 上限, 得分]`，下限含、上限不含；**得分范围必须 ≤ ±2**
  （引擎硬上限，超出会被定义校验拦下）
- 定义被改动后建议顺手跑一次 `thesis.defs.validate_def()` 确认无「区间未覆盖 / 得分超范围」问题
- 若改动了 `stages.drive_keys` 或 `pos_keys`，务必同步复核 `drive_full` / `pos_full`
  与 `verdicts` 的 `min_total` 档位（量纲变了档位含义会整体漂移）
