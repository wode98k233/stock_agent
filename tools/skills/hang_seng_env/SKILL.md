# Skill名称：恒生科技环境因子Skill
## 基础信息
- 版本：v1.0
- 描述：把「恒生科技现在能不能配」拆成 5 个可重复取数的因子，输出读数 + 评分 + 综合结论 + 信号命中 + 结论失效条件。**数据型技能**——只出判定，不产出报告。
- 所属分类：数据分析
- 适用场景：港股配置（港股通/恒生科技 ETF）、红利低波+恒生科技哑铃组合、南向资金跟踪、用户问「恒生科技能不能买 / 港股科技什么位置」

## 关联文件
- 工具注册入口：./main.py
- 计算引擎：`thesis/engine.py`（Web 台账页复用同一套，勿在技能层重复实现）
- 台账定义（阈值/判定矩阵可手改）：`data/thesis/hang_seng_tech.json`
- 定义加载与校验：`thesis/defs.py`
- 技能统一薄封装基类：`tools/thesis_skill_base.py`

## 目录层信息
- 关键参数：无（因子、阈值、判定矩阵全部来自台账定义）
- 核心目标：按定义取数 → 区间打分 → 综合结论；数据缺失标 `score=null`，不静默给 0 分
- 数据来源：`macro_indicator`（10Y 美债 / 10Y 中国国债 / 港元 HIBOR 1W / 合成美元指数）+ `index_daily`（恒生科技 HSTECH / 恒生指数 HSI）。**v1.1（2026-09-22）起 ⑤ 已由手工项改为自动因子，本台账已无手工项；v1.2 补回原设计的 ⑥ 美元指数（合成）与 ⑦ 港美利差，共 7 因子**
- 机制依据（74 个月月度实证，2020-08~2026-09，n=73）：恒生科技首先是一只港股、其次才是科技指数。分子端看中国（中国 10Y 变化 r=+0.28，加息期 +0.49），分母端看美债（美债 10Y 变化 r=−0.28，加息期 −0.45）——两轴方向相反且都有量级

## 工具列表
### 工具1：get_hang_seng_env
- 功能：获取恒生科技环境七因子读数与综合判定
- 调用入口：main.py.build_tools 中的 get_hang_seng_env
- 参数约束：无参数
- 返回结构：
  - `factors[]`：每项 `key/name/value/unit/score/status/detail/source/asof/stale/note`
    - `score` ∈ {-2,-1,0,1,2}，**null = 数据缺失，不等于中性**
    - `stale=true` → 引用时必须标注数据截止日（`asof`）
  - `total` 综合总分（仅统计有效因子）、`valid_count` / `factor_count`
  - `verdict` / `action`：结论档位与对应动作
  - `signals.buy[]` / `signals.warn[]`：`label/current/hit`
  - `invalidation[]`：`text/current/hit` —— **结论失效条件，命中即说明多头结论不再成立**
  - `metric_values`：各指标原始读数（供交叉引用）
  - `warnings[]`：取数降级、数据陈旧、定义缺项等提示
- `factors` 的 key 固定为：`us10_y`（美债10Y分母端）/ `dual_axis`（内外双轴）/ `crowding`（价格位置）/ `rel_hsi`（相对恒指强弱）/ `hk_liq`（港元流动性 HIBOR 1W）/ `usd_trend`（美元指数近20日变动 bp）/ `hk_us_spread`（港美利差 bp，阈值非单调）

### 工具2：describe_hang_seng_thesis
- 功能：获取台账元信息（标的口径、因子清单含机制说明、结论分档）
- 调用入口：main.py.build_tools 中的 describe_hang_seng_thesis
- 参数约束：无参数
- 返回结构：`thesis_id/name/asset_label/description/subject/factors[]/verdicts[]/problems[]`

## 使用指南

### 适用场景
- 用户问「恒生科技/港股科技现在能不能买、什么位置」→ 先取本因子包，再结合估值与持仓
- 哑铃组合（红利低波 + 恒生科技）的权重判断：**当恒科因子转正、红利因子转负时，才应提高恒科权重**（回测结论：固定权重不是最优，权重应跟着期望收益的相对变化走）
- 港股配置 / 南向资金跟踪：作为「环境是否顺风」的定量输入
- **结论失效条件必须一起呈现**：不能只报总分，命中失效条件时须显式说明

### 不适用场景
- 不选个股（恒生科技成分股是选股问题，不是环境问题）
- 不做回测（本技能跟踪论断，回测验证策略）
- 不提供预测，不提供买卖指令；**不做权重建议**（权重取决于个人风险承受能力）

### 输出解读要点
- 综合总分满分 ±10（5 因子 × ±2）；有因子缺失时按 `valid_count` 说明有效因子数，不得按满分归因
- **因子②（内外双轴）是本台账的核心机制**，判定矩阵 3×3。注意它与债基台账的「内外双紧」**语义相反**：
  - 债基以中债为主轴，「中债不动 = 冲击有限」
  - 恒生科技两轴对称，**中国利率上行对恒科是利好**（复苏→广告/电商/本地生活盈利改善，分子端），对红利低波与债基是利空
  - 某一轴不动时另一轴强度减半（±1），不是归零——归零会丢掉另一轴的真实信号
- `③ 价格位置` 是**港股指数**：没有中证指数公司估值源，故只用「点位对长期均线偏离度」一维，**不启用股息率分位**（detail 里会写明）
- `⑤ 港元流动性` 走港元 HIBOR 1W（`macro_china_hk_market_info`，日频自动，2017-03 至今），阈值按历史分位设定（p10=1.50 / p50=2.55 / p90=3.78）：HIBOR 低 = 港元资金充裕 = 利好港股。**v1.1 之前它是手工项，判据写的是「美债趋势性站稳 5% 以上」，与 ① 的美债水平同源、② 又取美债变动，同一变量被计三遍**——改自动源的同时也解掉了这个重复计分
- `⑥ 美元指数趋势` / `⑦ 港美利差`（v1.2 补回，来自独立仪表盘原设计）：
  - ⑥ 用**外管局人民币汇率中间价合成 DXY**（`tools/fetcher/akshare_ds.py::_calc_dxy`，6 种货币按 ICE 官方权重）。**只有变动幅度可用**：合成分的绝对水平含中间价政策因子偏差（与官方 ICE DXY 差约 2–3%），故阈值作用在「近 20 日变动 bp」上。取数需 `verify=False`——该站在本机代理链下过不了标准校验，这正是台账早期 note 所记「外管局 SSL 拒绝」的真身。
    ⚠️ 早期版本曾以「东财 `index_global_*` 本机不可达」为由**不做**美元指数因子，该判断已推翻：可行方案一直存在于用户的独立仪表盘里。
  - ⑦ 港美利差（HIBOR − 美债，bp）比单看 HIBOR 水平更贴近联系汇率的套息机制，**阈值非单调**：−250bp 以下反而判 0 而非 +1（深度倒挂是套息外流压力的表征，不是「宽松红利」），−50~−250bp 的温和倒挂才判有利。
- 因子数由 5 增至 7 后，`verdicts` 量纲同步由 ±10 校准到 ±14（档位 5/2/−1/−4 → 7/3/−1/−6），否则「偏有利」门槛会相对变松
- **刻意排除的两个变量**（不要自行补成因子）：
  - 纳斯达克：月度相关仅 +0.22（降息期 +0.05），「美股带港股」在月度粒度不成立，仅作对照
  - 南向资金：与同期恒科相关 +0.23、与**下期**仅 +0.08，是「追涨」的**同步**指标而非领先指标，**把它当买入理由是无效的**
- 阈值与判定矩阵是**主观设定**，不同研究者会给出不同结果——引用时须说明这一点

### 失败 fallback
- 返回 `{"error": ...}` 时优先检查：① `data/thesis/hang_seng_tech.json` 是否完整；
  ② `index_daily` 是否已有 HSTECH/HSI 日线（首次运行会自动采集）
- 部分因子 `score=null` 不算整体失败：用 `valid_count` 说明有效因子数继续分析

### 不要重试条件
- 同一轮对话内不要重复调用（单次调用已含全部 5 因子）
- 返回 `error` 时不要连读同参重试；接口不可达时重试无意义

### 阈值调整
- 改 `data/thesis/hang_seng_tech.json` 的 `thresholds` / `matrices` / `params` / `manual`，**无需重启**（带 mtime 缓存）
- 阈值表格式：`[下限, 上限, 得分]`，下限含、上限不含；**必须兜住 -99 ~ 99 两端**，否则值落在区间外会静默变成「数据缺失」
- 判定矩阵键为 `num_<up|down|flat>_denom_<up|down|flat>`（共 9 个），缺键会按中性处理并写进 warnings
- 定义被改动后建议跑一次 `thesis.defs.validate_def()` 确认无「区间未覆盖」问题
