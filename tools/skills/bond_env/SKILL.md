# Skill名称：债券基金环境因子Skill
## 基础信息
- 版本：v1.0
- 描述：把「现在买债基安不安全」拆成 6 个可重复取数的因子，输出读数 + 评分 + 综合结论 + 信号命中 + 结论失效条件。**数据型技能**——只出判定，不产出报告。
- 所属分类：数据分析
- 适用场景：债基配置 / 久期决策 / 固收类日报 / 用户问「债基还能不能拿 / 现在买债基安不安全」

## 关联文件
- 工具注册入口：./main.py
- 计算引擎：`thesis/engine.py`（Web 台账页复用同一套，勿在技能层重复实现）
- 台账定义（阈值/判定矩阵可手改）：`data/thesis/bond_fund.json`
- 定义加载与校验：`thesis/defs.py`
- 技能统一薄封装基类：`tools/thesis_skill_base.py`

## 目录层信息
- 关键参数：无（因子、阈值、判定矩阵全部来自台账定义）
- 核心目标：按定义取数 → 区间打分 → 综合结论；数据缺失标 `score=null`，不静默给 0 分
- 数据来源：`macro_indicator`（10Y 中国国债 / 10Y 美债 / Shibor 1W / 美元兑人民币中间价）+ `index_daily`（中证全债 H11001）+ 手工项（政府债供给，带陈旧判定）。**v1.1（2026-09-22）起 ④ 汇率、⑤ 赎回已接自动源，仅 ⑥ 政府债供给为手工项**
- 锚定依据（22 年数据，2004–2026 三轮加息周期）：中长期纯债基金指数 0 个负收益年；真正让债基亏钱的是「内外双紧」（中债与美债同步上行）与赎回负反馈

## 工具列表
### 工具1：get_bond_fund_env
- 功能：获取债基环境六因子读数与综合判定
- 调用入口：main.py.build_tools 中的 get_bond_fund_env
- 参数约束：无参数
- 返回结构：
  - `factors[]`：每项 `key/name/value/unit/score/status/detail/source/asof/stale/note`
    - `score` ∈ {-2,-1,0,1,2}，**null = 数据缺失，不等于中性**
    - `stale=true` → 引用时必须标注数据截止日（`asof`）
  - `total` 综合总分（仅统计有效因子）、`valid_count` / `factor_count`
  - `verdict` / `action`：结论档位与对应动作
  - `signals.buy[]` / `signals.warn[]`：`label/current/hit`
  - `invalidation[]`：`text/current/hit` —— **结论失效条件，命中即说明结论不再成立**
  - `metric_values`：各指标原始读数（供交叉引用）
  - `warnings[]`：取数降级、数据陈旧、定义缺项等提示
- `factors` 的 key 固定为：`coupon`（票息垫子）/ `double_tighten`（内外双紧）/ `funding`（资金面 Shibor 1W）/ `fx`（汇率约束）/ `redemption`（赎回压力）/ `gov_supply`（政府债供给）

### 工具2：describe_bond_fund_thesis
- 功能：获取台账元信息（标的口径、因子清单含机制说明、结论分档）
- 调用入口：main.py.build_tools 中的 describe_bond_fund_thesis
- 参数约束：无参数
- 返回结构：`thesis_id/name/asset_label/description/subject/factors[]/verdicts[]/problems[]`
- 用途：回答「这个台账看哪些因子、为什么这么设计」——因子清单从定义 JSON 动态读取，不会与台账页口径漂移

## 使用指南

### 适用场景
- 用户问「债基现在能不能拿 / 买债基安不安全」→ 先取本因子包，再结合持仓与久期
- 固收类日报：`cn10_y` 与 Shibor 1W 可作为利率与资金面环境的定量输入
- **结论失效条件必须一起呈现**：不能只报总分，命中失效条件时须显式说明

### 不适用场景
- 不选个券、不评单只债基产品（那是基金筛选的职责，本技能只给环境）
- **可转债基金不在范围内**：其波动来自权益属性（如近 3 月 −7.57%），与利率环境无关
- 不做回测、不提供预测、不提供买卖指令

### 输出解读要点
- 综合总分满分 ±12（6 因子 × ±2）；有因子缺失时按 `valid_count` 说明有效因子数，不得按满分归因
- **债基的定价锚是国内利率 + 央行政策，不是美联储**。中美利差已倒挂至 −332bp（2002 年以来最大），但美债 20 日冲击下中债各期限上行概率仅 47%–54%、中位数≈0，故美债**只作「内外双紧」的次要轴，不单独打分**
- `② 内外双紧` 以中债为主轴：**中债平稳一律判 0 分**，不能把「中债没动 + 美债上行」判成内外双紧——中国债市定价权在国内，美债上行只是情绪扰动。判定矩阵放定义 `matrices`，可改
- `① 票息垫子` 用中债 10Y：利率越低票息保护越薄，但当前处历史极低位、且资金面宽松，故低利率在本台账**判为有利**（与红利低波台账同向，但解读重点不同）
- `③ 资金面` 是**代理指标**：该源不含 DR007/R007（质押式回购），以 Shibor 1W 作为银行间资金面宽松度代理；资金面变化快，趋势窗口用 10 日 / 5bp
- `④ 汇率` / `⑤ 赎回` / `⑥ 政府债供给` 是**手工项**，`updated_at` 超期会标 stale 并在 warnings 里点名。赎回压力的 0/1/2 级参照 2022 年 11–12 月：一旦出现赎回负反馈，风险性质从利率风险升级为流动性风险
- 阈值与判定矩阵是**主观设定**，不同研究者会给出不同结果——引用时须说明这一点

### 失败 fallback
- 返回 `{"error": ...}` 时优先检查：① `data/thesis/bond_fund.json` 是否完整；
  ② 中债美债与 Shibor 接口是否可达
- 部分因子 `score=null` 不算整体失败：用 `valid_count` 说明有效因子数继续分析

### 不要重试条件
- 同一轮对话内不要重复调用（单次调用已含全部 6 因子）
- 返回 `error` 时不要连读同参重试；接口不可达时重试无意义

### 阈值调整
- 改 `data/thesis/bond_fund.json` 的 `thresholds` / `matrices` / `params` / `manual`，**无需重启**（带 mtime 缓存）
- 阈值表格式：`[下限, 上限, 得分]`，下限含、上限不含；**必须兜住 -99 ~ 99 两端**，否则值落在区间外会静默变成「数据缺失」
- 手工项（汇率/赎回/政府债）必须带 `updated_at` + `stale_days`，否则「手工数据永久有效」这个隐患会静默存在
- 定义被改动后建议跑一次 `thesis.defs.validate_def()` 确认无「区间未覆盖」问题
